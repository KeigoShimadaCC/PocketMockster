# Region contract

Mechanical rules every map file must follow. `docs/scenario.md` says what a place *is*; this file says
how it must be *wired*. `npm run validate:content` enforces most of it.

## Map shapes

| Kind | Size (w x h) | Border | Gates |
|---|---|---|---|
| Route / outdoor area | 20 x 24 | col 0 and col 19 = `T`, row 0 and row 23 = `T` | north: `,` at x=8,9 in row 0; south: `,` at x=8,9 in row 23 |
| Town | 22 x 20 | col 0 and col 21 = `T`, row 0 and row 19 = `T` | north: `,` at x=9,10 in row 0; south: `,` at x=9,10 in row 19 |
| Gym | 14 x 14 | `w` walls all around | entrance `M` mats at x=6,7 in row 12 |
| Interior (center/mart) | generated by `mockCenter` / `mockMart` | — | — |
| Dungeon (cave/plant/tube) | 20 x 24 | `w` or `T` border | as documented per map |

## Chain and warp coordinates

Route north gate `(8,0),(9,0)` warps to the town north-of-it at `(9,18),(10,18)`.
Town south gate `(9,19),(10,19)` warps to the route south-of-it at `(8,22),(9,22)`.
Town north gate `(9,0),(10,0)` warps to the next route at `(8,22),(9,22)`.
Route south gate `(8,23),(9,23)` warps to the previous town at `(9,18),(10,18)`.

```
mapletown -> route1 -> verdantcity -> verdantwoods -> thornbury -> route3 -> seasidecave
  -> tidewell -> route4 -> voltmere -> route5 -> bloomrest -> route6 -> cinderwake
  -> route7 -> zephyrheights -> route8 -> somnium -> nullpeak_1f -> nullpeak_summit
                                             somnium -> victorytrail -> summitnull
```

Legacy maps keep their existing coordinates (`mapletown`, `route1`, `verdantcity`, `center`, `mart`,
`gym`, `lab`); the contract above applies to every new map.

## Town interior doors (standard positions)

| Building | Door tile in town | Interior id | Interior exit target |
|---|---|---|---|
| Mock Center | `(4,4)` (tile `D`) | `center_<town>` | `(4,5)` |
| Mock Mart | `(12,4)` (tile `D`) | `mart_<town>` | `(12,5)` |
| Gym | `(11,8)` (tile `D`) | `gym<N>` | `(11,9)` |
| Extra building | `(17,4)` or `(6,12)` | per act | door tile + 1 south |

Interiors for centers and marts are generated: `mockCenter('thornbury', 'Thornbury', { to: 'thornbury', tx: 4, ty: 5 })`.

## Tiles

| Char | Meaning | Solid |
|---|---|---|
| `.` | path / floor | no |
| `,` | gate path (town/route seam) | no |
| `G` | tall grass (wild encounters) | no |
| `T` | tree / wall | yes |
| `W` | deep water | yes |
| `~` | shallow water, crossable with the Tide Badge (`badge_tide`) | conditional |
| `R` | roof | yes |
| `B` | building wall | yes |
| `D` | door (must have a warp on it) | no (warp) |
| `S` | sign (needs a `signs` entry) | yes |
| `w` | interior wall | yes |
| `F` | interior floor | no |
| `C` | counter (talk over it) | yes |
| `M` | door mat (interior exit) | no |
| `P` | starter table | yes |
| `o` | boulder | yes |
| `x` | lava, retracts on a timer (`lavaPeriod`) | conditional |
| `#` | wind tile, pushes the player along `windDir` | no |
| `_` | dark cave floor | no |

## Puzzle features (optional `GameMap` fields)

```ts
gates?:   { x, y, flag, text? }[]   // solid until flags[flag] is true
buttons?: { x, y, flag, toggle?, text? }[]  // A toggles the flag (toggle:false = set once)
oneWay?:  { x, y, dir }[]           // may only be entered while moving in dir
pads?:    { x, y, tx, ty }[]        // stepping on it teleports inside the map
windDir?: 'up'|'down'|'left'|'right'
lavaPeriod?: number                 // frames per on/off phase for 'x'
```

Gym puzzle per leader: 1 boulder maze (built), 2 one-way silk threads, 3 valve buttons draining `~`
rows, 4 switch gates, 5 hedge maze (tiles only), 6 timed lava, 7 wind tiles, 8 teleport pads.

## Content rules

- Every trainer NPC needs a globally unique `trainer.id` (`trainer_*`, `gymtrainer_*`, `leader_*`, `grunt_*`, `admin_*`, `elite_*`, `champion_kai`).
- `sight > 0` makes a trainer charge from a distance; leaders use `sight: 0`.
- Ground item ids must be globally unique (`<map>_<item><n>`).
- Encounter tables: 3-5 species, weights sum is free, `nightWeight` on 2-3 entries per route.
- Wild levels sit 4-8 below the current gym cap; trainer aces 1-2 below the leader's ace.
- Every map must be reachable from `mapletown` (validator errors otherwise).
